# Создание прайса услуги

`POST /api/services/{serviceId}/prices`

```json
{
  "price": 500.00,
  "validFrom": "2026-12-01"
}
```

`price` обязателен: неотрицательное число, до 10 цифр до запятой и 2 после неё. `validFrom` необязателен, по умолчанию — сегодняшняя дата сервера.

Ответ: 201 Created с полями `id`, `serviceId`, `price`, `validFrom`, `validTo` и заголовком Location на созданную запись.

- `GET /api/services/{serviceId}/prices` — история, начиная с последней даты.
- `GET /api/services/{serviceId}/prices/{priceId}` — запись прайса конкретной услуги.

Дата новой цены должна быть строго позже последней даты начала цены этой услуги. Иначе — 409 Conflict. Вставка задним числом перед существующими записями и замена цены в тот же день не поддерживаются этим API.

Предыдущий открытый период закрывается днём перед новой ценой. Уже закрытый период не продлевается. Будущая цена не меняет сегодняшнюю до наступления её даты. Изменение старого периода и создание новой записи выполняются одной транзакцией с блокировкой строки услуги, чтобы параллельные запросы не создали пересекающиеся периоды.

Неизвестная услуга или запись цены возвращает 404; ошибки валидации — 400. Используются действующие правила ADMIN и CSRF. Схема БД не меняется.

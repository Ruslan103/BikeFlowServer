# API скидок

Все методы требуют сессию пользователя с ролью ADMIN. Для POST, PUT и DELETE
нужен CSRF-токен, как и для остальных изменяющих запросов сервера.

| Метод | Путь | Результат |
| --- | --- | --- |
| POST | `/api/discounts` | Создание, 201 и Location |
| GET | `/api/discounts` | Список, сортировка по названию и ID |
| GET | `/api/discounts/{id}` | Получение скидки |
| PUT | `/api/discounts/{id}` | Полная замена названия и процента, 200 |
| DELETE | `/api/discounts/{id}` | Удаление, 204 |

Тело POST и PUT:

```json
{"name":"Постоянный клиент","percentage":10.50}
```

Оба поля обязательны. Название: не пустое, не более 100 символов;
краевые пробелы удаляются. Процент: от 0 до 100 включительно, максимум два
знака после запятой. Ответ содержит `id`, `name`, `percentage`.

Ошибки возвращаются в существующем формате ProblemDetail:
400 — ошибка валидации, 404 — скидка не найдена, 409 — конфликт данных
(в частности, удаление скидки, на которую ссылается услуга бланка).
Связанные бланки при удалении скидки не удаляются.

PUT меняет справочник скидок. Сохранённые суммы `priceWithDiscount` в бланках
не пересчитываются; отображаемые название и процент связанной скидки берутся
из обновлённого справочника.

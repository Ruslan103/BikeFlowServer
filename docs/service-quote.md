# Расчёт услуг бланка

`POST /api/work-orders/services/quote` (сессия ADMIN и CSRF-токен).
Не сохраняет бланк и не требует выбранного клиента или велосипеда.

```json
{"services":[{"serviceId":1,"discountId":7}]}
```

Ответ: `services` со стоимостью, сведениями о скидке и итоговой ценой каждой
строки; `serviceCount`, `totalPrice`, `totalWithDiscount`.
Округление каждой строки до двух знаков, HALF_UP; затем сложение строк.
Каждая добавленная строка считается отдельной услугой, повторения разрешены.

Если `priceWithoutDiscount` отсутствует, используется действующий прайс.
Для существующих строк можно передать сохранённые `priceWithoutDiscount`,
`priceWithDiscount` и `serviceNameSnapshot`, чтобы получить сводку без
переоценки старого бланка. При выборе другой скидки нужно убрать
`priceWithDiscount`: сервер рассчитает новую итоговую цену.
Отсутствующая скидка означает отсутствие скидки.
Цена неотрицательная, до 10 целых и 2 дробных знаков; максимум 1000 строк.

Ошибки: 400 — неверные данные или нет действующего прайса для новой строки;
404 — услуга или скидка не найдена. Формат — существующий ProblemDetail.
Сохранение бланка использует существующий API work-orders и его правила прайса.

# Интеграция бланков с Trello

## Настройка

Сохраните API-ключ и **пользовательский токен Trello** в существующих полях
личного кабинета сервера. Токен для создания и изменения карточек должен
иметь права `read,write` и доступ к выбранной доске. Atlassian API token для
Jira не заменяет пользовательский токен Trello.

Инструкция Trello: https://developer.atlassian.com/cloud/trello/guides/rest-api/authorization/

Ключ и токен читаются из настроек при каждом запросе: смена секретов не требует
перезапуска. Они передаются Trello в Authorization, не в URL и не в ответах API.
После установки этого обновления нужен перезапуск сервера для загрузки кода
и добавления статуса LINKED существующим инициализатором schema.sql.

## API

Все маршруты требуют ADMIN, изменяющие запросы дополнительно требуют CSRF.

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/trello/connection` | Проверка ключа и токена, данные аккаунта |
| GET | `/api/trello/boards` | Открытые доски |
| GET | `/api/trello/boards/{id}/lists` | Открытые колонки доски |
| GET | `/api/trello/boards/{id}/labels` | Метки доски |
| GET | `/api/trello/lists/{id}/cards` | Карточки колонки |
| GET | `/api/work-orders/{number}/trello` | Актуальная карточка связанного бланка, включая idBoard, idList и idLabels |
| PUT | `/api/work-orders/{number}/trello` | Привязать существующую карточку: `{"cardId":"24-символьный ID или 8-символьный shortLink"}` |
| POST | `/api/work-orders/{number}/trello/card` | Создать или обновить карточку сохранённого бланка |

Тело POST:

```json
{"listId":"24-символьный ID колонки","labelIds":["24-символьный ID метки"]}
```

Ответ POST/PUT: `blankNumber`, `cardId`, `url`, `status` (LINKED).
Одна карточка может быть связана только с одним бланком. При обновлении уже
связанного бланка используется та же карточка. Доска определяется по колонке;
метки проверяются на принадлежность этой доске.

Название и описание формируются на сервере из сохранённого бланка: номер,
ФИО клиента, выбранный контакт, услуги с исходной и итоговой стоимостью,
комментарий для себя и заявленная неисправность. Свободное редактирование
описания в Trello не меняет справочники клиентов и услуг: при следующем
сохранении из приложения описание формируется заново.

Бланк сохраняется в БД отдельно от внешней операции. При ошибке Trello клиент
сообщает, что бланк сохранён, и остаётся в режиме его редактирования.

## Обновление клиента

Доски, колонки и метки загружаются через сервер. Для существующей карточки
читаются актуальные выборы из Trello. Фоновая проверка каждые 30 секунд
работает только пока панель видна и не выполняется другая операция бланка.
Несохранённый локальный выбор имеет приоритет до сохранения или открытия
другого бланка. В комбобоксе меток поддержан выбор нескольких меток;
повторный выбор снимает метку, «Без меток» очищает набор.

Без выбранной колонки новый бланк сохраняется без карточки. Для уже связанного
бланка недоступная колонка считается ошибкой синхронизации, чтобы не терять связь.

## Повторы и ограничения

Изменения бланка и его привязки используют блокировку строки в БД.
Повтор POST обновляет привязанную карточку, не создавая новую.
Для восстановления после потери ответа на создание описание содержит
стабильный маркер бланка; сервер ищет его среди всех карточек выбранной доски.
При нескольких совпадениях возвращается 409. После неопределённого исхода
создания не меняйте доску и не удаляйте маркер до восстановления привязки:
внешний Trello API и локальная БД не имеют общей транзакции.

Webhook и разбор изменений текста карточки обратно в поля бланка не включены.
Доска, колонка и метки обновляются в обе стороны при чтении и сохранении.
Удаление бланка не удаляет карточку Trello.

Ошибки: 400 — неверные ID/метки; 404 — нет бланка/карточки; 409 — конфликт
привязки/архивная карточка; 502 — ошибка ответа или доступа Trello; 503 —
нет ключа/токена, статуса LINKED или превышен лимит Trello. Внешние тела
ошибок и секреты не возвращаются клиенту.

Пакеты сервера: `integration.trello` — транспорт и доступ к секретам,
`service.trello` — операции бланка и формирование карточки, `dto.trello` — DTO.
Пакеты клиента: `trello.api`, `trello.model`, `trello.ui`.

# BikeFlowServer 1.0.0

Первый релиз сервера BikeFlowServer для Windows x64.

## Установка

Скачайте `BikeFlowServer-1.0.0-Windows-x64.zip`, распакуйте архив и запустите `start.bat`. При первом запуске скрипт создаст `.env` и откроет его в Блокноте. Задайте уникальные пароли базы данных и администратора, сохраните файл и повторно запустите `start.bat`.

Архив содержит Docker-образы сервера и PostgreSQL, Docker Compose-конфигурацию и скрипты запуска. Устанавливать Java или Maven не нужно. Требуется Docker Desktop с поддержкой Linux-контейнеров.

## Доступ

- Панель администратора: `https://localhost:8443/admin`
- Страница входа: `https://localhost:8443/login`
- HTTP: порт `8080`

Для доступа из локальной сети укажите адрес компьютера-сервера в `BIKE_TLS_DNS_NAMES` или `BIKE_TLS_IP_ADDRESSES` в `.env` **до первого запуска**.

Самоподписанный HTTPS-сертификат создаётся при первом старте. `stop.bat` останавливает контейнеры, сохраняя базу и настройки; `logs.bat` показывает журнал сервера.

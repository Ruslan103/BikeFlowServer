# BikeFlowServer 1.0.1

Исправлена инициализация таблицы комментария по умолчанию для заказов. Исправление применяется автоматически при запуске обновлённого сервера и сохраняет существующие данные PostgreSQL.

Скачайте `BikeFlowServer-1.0.1-linux-amd64.zip` и распакуйте архив. В Windows запустите `start-windows.bat`; в Linux/macOS выполните `sh ./start-linux.sh`. Для существующей установки сохраните свой `.env` и используйте прежний Docker volume с базой данных.

Архив содержит Docker-образы сервера и PostgreSQL, Docker Compose-конфигурацию и скрипты запуска для Windows и Linux/macOS. Требуется Docker с поддержкой Linux-контейнеров. Образ собран для `linux/amd64`; Java 21 уже включена в образ, устанавливать JVM или Maven на хост не нужно.
